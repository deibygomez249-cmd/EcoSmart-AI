1. Project Title & Problem Statement

Title: EcoSmart AI: Smart Home Energy Analysis and Prediction System.

Problem: The increase in household energy consumption and the lack of intuitive tools for users to understand their usage patterns. Users receive high electricity bills without knowing which appliances cause the spikes or how to optimize their consumption.

Justification: This system provides an intelligent web platform that not only allows users to register their devices but also uses Machine Learning (Regression, Clustering, Anomaly Detection) to predict consumption, detect abnormal energy spikes, and provide actionable insights.

2. Objectives

General Objective: Develop a private web-based intelligent system using Python and Machine Learning to analyze, predict, and monitor smart home energy consumption.

  • Specific Objective 1: Preprocess the UCI Appliances Energy Prediction dataset (19,735 records).
  • Specific Objective 2: Train and evaluate ML models (Random Forest, Isolation Forest, K-Means) for prediction and anomaly detection.
  • Specific Objective 3: Build a secure Flask web application with user authentication and device management.
  • Specific Objective 4: Deploy the system on Render and validate its real-world usability.

3. Methodology (CRISP-ML)

  • 1. Business Understanding: Identifying the need for household energy management and user device tracking.
  • 2. Data Understanding: Exploring the 19,735 records dataset, identifying variables (Temperature, Humidity, Appliances).
  • 3. Data Preparation: Handling missing values, chronological split (80/20), and scaling (StandardScaler).
  • 4. Modeling: Training Linear Regression, Random Forest, HistGradientBoosting, Isolation Forest, and K-Means.
  • 5. Evaluation: Using MAE, RMSE, R2, Silhouette score, and Confusion Matrices.
  • 6. Deployment: Implementing the Flask app with SQLite database, deployed on Render.
